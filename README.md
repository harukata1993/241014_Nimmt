# 俺たちのNIMMT

カードゲーム「ニムト（6 nimmt!）」をもとにした、2〜8人で遊べる対戦カードゲームです。
Python の標準ライブラリだけで動くので、追加のインストールは要りません。

遊び方は3通りあります。

- **Web版（ローカル）**: 1台のPCのブラウザを交代で使って遊ぶ
- **Web版（オンライン）**: ルームを作って、離れた友だちと遊ぶ
- **ターミナル版**: コマンドラインで遊ぶ

コンピューター対戦相手（AI / ランダム）を混ぜることもできます。

## 必要なもの

- Python 3（3.12.4 で動作確認済み）
- オンライン対戦を開くときだけ: [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)

## 遊び方

### Web版（ローカル）

```bash
python3 nimmt_web.py
```

ブラウザで <http://127.0.0.1:8000> を開き、「Local game」タブで人数と各プレイヤーの種類を選んで始めます。
画面を共有して遊ぶ前提なので、手札は手番のプレイヤーにだけ表示されます。

### Web版（オンライン）

部屋を開く人（ホスト）が次のコマンドを実行します。

```bash
python3 start_online.py
```

しばらくするとターミナルに `https://xxxx.trycloudflare.com` のような一時URLが表示されます。

1. ホストはそのURLを開き、「Online game」タブで名前と定員を入れてルームを作ります
2. 表示されたルームコード（8文字）とURLを友だちに送ります
3. 友だちはURLを開き、ルームコードと名前を入れて参加します
4. 全員が準備完了になったら、ホストがゲームを開始します

ホストはロビーで AI / ランダムのプレイヤーを追加することもできます。
ゲーム中はホストのPCでサーバーを動かし続けてください。`Ctrl+C` で終了します。

### ターミナル版

```bash
python3 nimmt.py
```

人数（2〜8）と、各プレイヤーの種類（`human` / `ai` / `random`）を入力して始めます。

## ルール

### カード

- 1〜104 のカードを使います
- カードごとに失点（牛の数）が決まっています

| カード | 失点 |
| --- | --- |
| 55 | 7 |
| ゾロ目（11, 22, 33 …） | 5 |
| 一の位が 5（5, 15, 25 …） | 3 |
| 一の位が 0（10, 20, 30 …） | 2 |
| それ以外 | 1 |

### 進め方

1. 各プレイヤーに手札が10枚配られ、場には4枚のカードが1枚ずつ並んで4つの列になります
2. 全員が手札から1枚を同時に選びます
3. 選ばれたカードは小さい数字から順に場へ置かれます
   - 「列の最後のカードより大きく、差がいちばん小さい列」の末尾に置きます
   - 置いたカードがその列の **6枚目** になったら、前の5枚を引き取って失点になり、置いたカードが新しい列の先頭になります
   - どの列の最後のカードよりも小さいときは、好きな列を選んで全部引き取り、置いたカードがその列の先頭になります
4. 手札がなくなるまで 2〜3 を繰り返します

### 勝ち負け

- そのラウンドで失点がいちばん少なかった人がラウンドの勝者です（同点なら全員が勝者）
- 勝利数と失点はラウンドをまたいで累計され、何ラウンドでも続けて遊べます

### コンピューター対戦相手

- `ai`: 手札でいちばん大きいカードを出します
- `random`: 手札からランダムに出します

## 注意事項

- オンライン対戦の一時URLは、**知っている人なら誰でもアクセスできます**。
  ルームに入るにはルームコードが必要ですが、それ以外の認証はありません。URLとルームコードは信頼できる相手にだけ共有してください。
- 一時URLは `start_online.py` を起動するたびに変わります。
- ゲームの状態はサーバーのメモリ上にだけあります。サーバーを止めると、進行中のゲームは消えます。
- オンラインのルームは、2時間操作がないと自動で消えます。
- サーバーはポート 8000 を使います。ほかのアプリが使っていると起動できません。

## 開発者向け

### テスト

```bash
python3 -m unittest discover -s tests
```

### ファイル構成

| パス | 内容 |
| --- | --- |
| `nimmt.py` | ゲームのルールとターミナル版 |
| `nimmt_web.py` | Webサーバーとローカル対戦の進行 |
| `nimmt_online.py` | オンライン対戦のルーム管理 |
| `start_online.py` | Webサーバーと Cloudflare Quick Tunnel をまとめて起動 |
| `web/` | ブラウザ画面（HTML / CSS / JavaScript） |
| `tests/` | テスト |
